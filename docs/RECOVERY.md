## Метод

В логах Grok два независимых источника:

- `rewind_points.jsonl` — полные снимки файлов после каждого шага;
- `updates.jsonl` — диффы правок (`old_string` → `new_string`).

Для каждого файла берётся **последний снимок**, затем доклеиваются правки, сделанные после него.
Если правка не ложится точным совпадением — нормализация переводов строк, затем сравнение
с гибкими пробелами. Так собрано 28 файлов из 31 (три оставшихся — одноразовые `_`-скрипты).
